# ToolWise Lab English-first static website about practical AI software, designed for GitHub Pages. ## Structure - `index.html`: homepage - `tools/`: searchable tool directory - `comparisons/`: comparison hub - `guides/`: practical articles - `assets/css/style.css`: responsive design - `assets/js/main.js`: mobile navigation, search and footer year - `about.html`, `affiliate-disclosure.html`, `privacy.html`, `contact.html`: supporting pages ## Publish with GitHub Pages 1. Create a **public** GitHub repository named `toolwise-lab`. 2. Upload the **contents** of this folder to the repository root. `index.html` must be at the root. 3. Open **Settings → Pages**. 4. Under **Build and deployment**, select **Deploy from a branch**. 5. Select branch `main` and folder `/(root)`, then Save. 6. Wait for publication. The URL normally looks like `https://YOUR-USERNAME.github.io/toolwise-lab/`. ## Before promotion - Verify availability of the ToolWise Lab name and any domain you choose. - Add a real editorial contact email. - Complete the privacy notice for the services actually enabled. - Join affiliate programs before inserting affiliate links; disclose those links clearly. - Do not claim independent testing unless the tool has actually been tested. - Verify current pricing, features, regional availability and terms with providers. - Add analytics and advertising only after updating privacy/cookie disclosures as needed. ## Important This is a first working foundation, not a finished monetized publication. Directory descriptions are introductory; official links are not affiliate links. No affiliate account, ad account, analytics service or custom domain is connected.
