# ToolWise Lab

English-first static website about practical AI software, built for GitHub Pages.

## Structure
- `index.html`: homepage
- `tools/`: searchable AI tool directory
- `comparisons/`: comparison hub
- `guides/`: practical articles
- `assets/css/style.css`: responsive design
- `assets/js/main.js`: mobile navigation and directory search
- Supporting pages: about, affiliate disclosure, privacy and contact

## Publish
Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save. Expected URL: https://lausan05.github.io/toolwise-lab/.

## Before promotion
Add a real contact email; complete the privacy notice before enabling analytics, ads, cookies, forms or tracking; join affiliate programs before inserting affiliate links; verify current pricing, features and terms with providers. This is an initial foundation, not a finished monetized publication. Current provider links are official non-affiliate links. No analytics or advertising is connected.
